# 🚀 Proyecto Frontend con Angular 17 y Devexpress 

Este repositorio contiene el proyecto desarrollado en Angular 17 y DevExpress.

## 🛠️ Tecnologías y Herramientas
* **Angular V17**: Framework principal.
* **TypeScript**: Lenguaje de programación.
* **Thunder Client**: Extensión de VS Code para pruebas de API (Sustituto de Postman).
